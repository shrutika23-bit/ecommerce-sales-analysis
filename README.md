# E-Commerce Sales & Customer Analysis

## Project Overview
This project analyzes e-commerce sales data to identify
revenue trends, top-performing products, city performance,
and product category profitability.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
600 practice sales records from 2025.

## Analysis
- Business KPIs
- Product revenue analysis
- Monthly revenue trends
- City-wise sales comparison
- Profit by product category

## Business Value
The analysis helps identify strong-performing products,
sales trends, geographic opportunities, and profitability
patterns.

## Note
This is a portfolio project using a practice dataset.

## How to Run

1. Download the project notebook and dataset from this repository.
2. Open the notebook in Google Colab.
3. Upload the CSV dataset when prompted.
4. Run all cells to perform the analysis.

## Project Files

- `Ecommerce_Sales_Analysis.ipynb` - Python analysis notebook
- `ecommerce_sales_analysis_dataset.csv` - Practice dataset
- `visualizations` - Sales analysis charts
